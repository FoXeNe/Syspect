# Ближайшие задачи Syspect

## Первый рабочий отчёт

- [ ] Создать Go-модуль и добавить команду `syspect analyze`.
- [ ] Прочитать `/proc/meminfo`: вывести общий объём RAM, `MemAvailable`, общий и занятый swap.
- [ ] Добавить тесты парсинга `/proc/meminfo` на фикстурах.
- [ ] Показать общий объём и доступное место на корневой файловой системе.
- [ ] Посчитать загрузку CPU по двум чтениям `/proc/stat` за короткий интервал.
- [ ] Показать PSI памяти и I/O, где они доступны; не подменять отсутствие данных нулём.
- [ ] Собрать бинарник и проверить `syspect analyze` на Linux без `sudo`, Docker и systemd.

## После базового отчёта

- Добавить данные о процессах, Docker и systemd journal.
- Добавить подсказки по диагностике и вывод в JSON (`--json`).
- Воспроизвести нехватку места и нехватку памяти в тестовой VM. Первым описать сценарий, который пришлось разбирать на своём сервере.
- Настроить CI и выпустить Linux-бинарник.
