# Syspect

CLI для диагностики Linux. Хочу собрать в одном отчёте то, что сейчас приходится проверять вручную: сколько места осталось на диске, что заняли Docker и журналы, хватает ли памяти и есть ли задержки из-за I/O.

Первая команда, `syspect analyze`, пока в разработке. Она будет только читать данные. Удаление файлов и изменение настроек в MVP не входят.
